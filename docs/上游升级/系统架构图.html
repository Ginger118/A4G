序流 v0.3 · 材料理解与上游任务草案

2026-11-13｜实线为本轮已实现路径；虚线为后续研究接口。可选Milvus/MinIO适配存在，服务未联调。SSE传输阶段事件和已生成回答的分段，不宣称模型逐Token流。

职责与调用逻辑

main.py 注册 build_router(actor)，身份/材料校验后 upstream_events() 建图；StateGraph按缺项条件分支，retrieve_evidence调用带用户与材料范围的rag.search，compose_response负责回答或固定能力目录的只读草案，validate_contract检查来源、依赖与执行权限。每个请求的图检查点独立保存，跨轮摘要与理解记录按owner/session隔离。

PDF上传：main.upload_pdf → documents.ingest_pdf → 按页提取/原文哈希 → OriginalStore → SQLite片段；查看原PDF前再次校验资产归属。普通对话和原四工具路径继续独立运行，草案流程不越过Executor执行。

课程映射：DAY2模板、DAY3 Pydantic、DAY4文档、DAY7/9图与状态、DAY9.5检查点、DAY11 SSE。MySQL、任意NL2SQL、扫描页OCR、BOS在线和显式规划执行均未集成。

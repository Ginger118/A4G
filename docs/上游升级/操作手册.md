# 序流 v0.3 操作手册

核对日期：2026-11-13。名称保持《基于 LangChain 的电力知识问答与辅助分析系统的设计与实现》。产品定位扩展为电力知识、材料理解与只读任务草案，采用课程衔接架构的第一阶段；不是全部目标架构已落地。

## 1. 工作目录与安装

```sh
cd /Users/zz/Desktop/A4G
uv sync --locked
cd src/frontend
npm ci
npm run build
cd ../..
```

使用 Python 3.12，Node.js 22。项目有独立 `.venv` 和 `uv.lock`，不修改课程环境。不要沿用全局 Python 直接启动：全局 LangGraph 检查点包曾出现 `writes_sort_key` 版本不兼容，锁定环境已解决。新装若 uv 不在 PATH，先按官方 uv 安装方法安装。

## 2. 启动与配置

本机已授权复用环境密钥，仅用于 api.deepseek.com：

```sh
cd /Users/zz/Desktop/A4G
uv run --locked python run.py --use-authorized-deepseek-env
```

若新环境没有该凭据，先在本机 `.env` 配置 `AGENT_API_KEY`，然后运行 `uv run --locked python run.py`。只在 `.env` 不存在时从 `config/.env.example` 创建；不要覆盖已有私密配置。密钥不写进文档、源码、浏览器或 Git。

打开 http://127.0.0.1:8018/ 。`/api/health` 应返回 `status=ok, version=0.3.0`。教学账号说明见根 README 的原账号说明或界面；只在本机使用。停服在启动终端按 Ctrl+C，不要删除 `.runtime`。

无模型时选择界面的“规则演示”。规则演示执行真实切分、检索与校验，但不冒充模型生成。

## 3. 测试输入与预期输出

1. 在电力知识库上传 `data/知识库/上游任务教学样例.pdf`（两页合成教学数据）。应显示 PDF 已入库、真实片段及页码。重复上传内容相同的 PDF 应返回已有文档，不重复创建。
2. 切换工作台“任务理解与草案”，问“资料中蓝槐线路的教学复核编号是什么？请给出引用。”真实模式应回答 QH-5817，并显示第2页来源；展开来源点“查看原 PDF”可定位原文件。此为教学事实，不是真实业务数据。
3. 上传线路 CSV（三列 `line_id,active_power_mw,limit_mw`，三行数据分别为 `A,100,100`、`B,-120,100`、`C,70,100`），并导入现有电力说明。问“请为已选线路 CSV 制定给定有功限值检查与报告的分析步骤。”应返回读取/计算/检索/报告四步草案、输入内容版本及来源。`ready_for_planner` 只表示可送规划器检查，执行授权仍为 false。
4. 问“帮我优化一下 BOS 场景线路状态”，应追问必要目标/场景/断面并标注数据源尚未接入。不会调用 BOS 或修改模型参数。
5. 执行记录页可查看任务理解记录并继续同一会话；选择历史记录本身不产生模型调用。当前每轮图检查点落库，重试会重新校验本轮范围；不宣称支持任意中间节点的自动续跑。
6. 选择原“工具分析”才进入既有 Planner/Executor。以上三行 CSV 应得到 3 条、1 条越限，B 为 120%，A 恰好 100% 不越限。
7. 扫描/空白页 PDF、加密/损坏 PDF 显式拒绝，不能伪装成已识别。PDF 最多10MB/100页；TXT/Markdown 保留2MB限制。图片语义仍走原独立视觉入口，OCR 尚未接入。

## 5. Milvus / MinIO 适配配置

默认 `AGENT_VECTOR_BACKEND=memory`、`AGENT_OBJECT_BACKEND=local`，不要求启动容器，保证单机可运行。扩展接口代码分别是 `repositories/milvus.py:search_vectors()`、`documents.py:OriginalStore`；本轮未对外部服务做联调。

需要服务时，安装 `uv sync --locked --extra enterprise`，在本机 `.env` 设置 Milvus URI 与 MinIO endpoint、私有 bucket 和访问凭据，再切换后端变量。MinIO默认TLS；只有明确是本机明文测试服务时才设 `AGENT_MINIO_SECURE=false`。请复用已经核验可用的课程服务配置，勿启动含未知来源镜像或固定公开凭据的示例。配置服务不可用时应显式报错，不悄悄回退冒充服务成功。

Milvus 后端仍使用同一字符哈希向量，不等于预训练语义检索；真正语义嵌入、Dense/Sparse融合、重排和MinIO/Milvus服务实测为下一轮工作。MySQL/NL2SQL、BOS在线适配与显式规划执行尚未接入。

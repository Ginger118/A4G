# 紫色深浅主题操作手册

2026-11-16，A4G v0.6的前端样式迭代，不更换技术栈。

工作目录 `/Users/zz/Desktop/A4G`。沿用现有课程环境，启动 `uv run --locked --extra enterprise python run.py --course --use-authorized-deepseek-env`；服务未启动时先按原课程手册启动Docker/Ollama和course_stack.py up。访问 http://127.0.0.1:8018/ 。

默认深色，右上角太阳/月亮按钮切换深浅；登录页也有切换。选择仅保存到当前浏览器localStorage的a4g-theme，不是账号服务端偏好；浏览器不允许存储时仍能当次切换，刷新持久化不保证。已有浅色选择会被保留。

预期：深色主背景、紫色强调和清晰紫色渐变Logo；浅色保持紫白；欢迎区只有标题和建议，无中间单独的“序”。聊天记录中的助手标识与左上品牌不属于此次移除范围。右栏、输入框、知识库、设置、附件与弹窗使用相应颜色。

修改主题在src/frontend/src/theme.css调整语义变量；theme.tsx提供initial/useTheme/ThemeToggle；main.tsx接入主题入口，ChatWorkspace.tsx移除欢迎标记。修改后执行 `npm run build --prefix src/frontend`，刷新浏览器。

本轮验证：TypeScript/Vite构建通过；浏览器实际深浅切换、刷新记忆、最终深色三栏无中间标记通过，并观察知识库和设置页。没有重跑真实模型、后端回归、手机专项、逐项对比度认证或每个弹窗的穷举测试。旧后端验收仅为历史，不计本轮成绩。无Git提交/push。

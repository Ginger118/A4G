## 03 / 有条件采用：用评估决定是否保留

|课程能力|当前→建议|优点|代价与边界|决策与准备|
|---|---|---|---|---|
|RRF与重排<br>DAY10 / 查询5.7—5.8|当前Dense Top-K。<br>两路召回后RRF去重，再可选Rerank。|RRF组合不同排序；重排可筛掉不相关候选，课程链路清晰。|只有一路时RRF价值有限；重排增加耗时/用量，云模型涉及资料外发。|条件采用｜先混合召回；统一chunk_id与来源编号；测Top-K、空候选、超时及不重排退路。|
|HyDE<br>DAY9 / 查询5.5|当前原问题直接检索。<br>仅疑难/低召回问题生成假设文档后再检索。|可能弥补提问与资料表述差异；沿用课程按需分支。|额外生成调用；可能带入错误术语；假设文档不能作为事实来源。|条件采用｜保留原问题分支；用低召回题单变量对照，无收益即关闭。|
|实体识别/指代<br>DAY8—9 / 向量4.3、查询5.3|当前意图、对象范围与前轮契约。<br>先做设备编号/资料对象轻量抽取。|改善“这条线路/上一份资料”的对象定位，未来TaskContract更明确。|全量实体图谱及模型自动合并成本高；错误指代会扩大检索范围。|条件采用｜先定义实体ID与别名，低置信度追问；每轮重验权限，不自动继承执行授权。|

|多模态嵌入/VLM<br>DAY8 / 向量4.2；DAY7图像|当前文字向量；独立图片入口未验视觉可用。<br>图表语义可另接VLM/多模态模型。|可扩到图中文字之外的图表描述/图文检索；与PDF业务相关。|云端费用、格式/维度变更；识图推测会进入知识库，需审核；不能把OCR当VLM。|条件采用｜先本地OCR；收集带标准答案的图表，确定模型与数据使用授权，再独立验收。|

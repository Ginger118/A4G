怎么讲给老师听

我们先做一个完整的 LangChain 应用，提供对话、知识上传、递归切分、检索引用和工具调用。电力只是具体的演示场景，线路计算由程序完成，模型负责理解、工具选择和文字解释。

为了服务后续课题，规划器和执行器已经分离。未来在相同工具、数据和执行条件下，替换 Planner，再补充目标验收与动作语义，就能开展显式规划的对照实验。

“A 到 B”表示从当前状态走向满足约束的目标集合。B 不一定是唯一点，也不必是一个几何平面。虚线部分尚未接入当前系统。

怎么打开和修改

只看图：直接打开本 HTML，或用 Mac“预览”打开 PNG。SVG 可在浏览器中无损放大。

在 VS Code 修改：安装 Henning Dieterichs 发布的 Draw.io Integration，再打开同目录的 .drawio 文件；在底部切换两页，双击文字即可编辑。

Visio：你说的“visto”大概率指 Microsoft Visio。它是微软的流程图与架构图工具，常用格式为 .vsdx。Windows 可用桌面版；Mac 使用网页版，编辑能力取决于账号与订阅。本次 .vsdx 已做结构与页面解析检查，尚未在微软 Visio 中实机验证。

更完整的步骤与讲解见同目录 打开与讲解说明.md。本页面不访问外部资源，不依赖应用运行；链接仅在你点击时打开。

# A4G 项目图解与打开说明

日期：2026-11-03。依据桌面 A4G 项目的当前 README、教师演示说明与 Planner 接口整理。

## 先打开哪一个

直接双击 `打开看图.html`，浏览器即可查看两张图和讲解，不依赖项目启动，也不需要安装 Visio。

如果 HTML 被编辑器打开，在 Finder 中右键 → 打开方式 → Safari 或 Chrome。

## 文件分别有什么用

| 文件 | 用途 | 如何打开 |
| --- | --- | --- |
| 打开看图.html | 两张图与讲解一起阅读 | 浏览器打开，无需联网 |
| 01-前期思路-思维导图.png | 给老师解释前期思路 | Mac 预览；也可插入 Word/PPT |
| 02-系统架构图.png | 展示当前模块、调用路径和未来接口 | Mac 预览；也可插入 Word/PPT |

| A4G-思维导图与架构图.vsdx | Visio 可编辑文件，共两页 | Windows 版 Microsoft Visio；Mac 可尝试 Visio 网页版 |

另外提供两张单图的 `.vsdx`，便于分别打开与分享。两页合并文件在绘图软件底部切换页面。

## 在 VS Code 里编辑（适合你现在的工作方式）

1. VS Code 打开桌面的 `A4G` 文件夹。
2. 打开扩展，搜索 `Draw.io Integration`，选择 Henning Dieterichs 发布的版本（扩展 ID：`hediet.vscode-drawio`）。
3. 打开 `docs/项目图解/A4G-思维导图与架构图.drawio`。
4. 双击文字修改，拖动方框与连线；通过底部页签切换两张图，按 Command+S 保存。
5. 若仍显示 XML，右键文件 → 打开方式 / Open With → Draw.io Editor。

也可以在 https://app.diagrams.net 打开编辑器，选择本地设备，通过“文件 → 打开自 → 设备”打开 `.drawio`。保存时保留 `.drawio` 格式。无需把项目密钥、运行库或用户上传文件交给绘图工具。

## “visto”是什么

按本次上下文，你大概率指 **Microsoft Visio**。它是微软的流程图、架构图与组织结构图绘图软件，和写代码的 Visual Studio Code 是两个产品。现代 Visio 图纸通常是 `.vsdx` 文件。

微软没有 macOS 桌面版 Visio，Mac 可以使用 Visio 网页版。具体查看和编辑权限取决于你的微软账号及订阅。若使用网页版，先将 `.vsdx` 放进自己的 OneDrive/SharePoint，再按微软页面说明打开。

本次 `.vsdx` 含独立文本框与矢量图形，不是将 PNG 改后缀。已检查 ZIP/XML 结构、关系目标、页面和图形可解析性；尚未在微软 Visio 中实机打开验证。不同软件的字体、自动换行或连线样式可能略有差异，Mac 上优先使用 `.drawio` 编辑。

## 两张图怎么讲

### 图一：为什么做这个项目

最初希望完成一个能承接后续课题的通用 Agent 基座。为保证课程作品本身完整，先实现对话、文档上传、切分、检索、工具调用与报告。电力提供知识材料和线路表这个具体场景，业务复杂度保持轻量，让老师能快速理解基础能力。

现阶段的成果是《基于 LangChain 的电力知识问答与辅助分析系统的设计与实现》。它能单独演示，也保留 Planner 与 Executor 分离的接口，未来可以在相同工具和执行条件下替换规划器做实验。

“从 A 到 B”可理解为：从已有数据、产物和执行状态出发，通过合法动作到达满足约束的目标集合。B 不一定是唯一点，也不必是几何意义上的平面。图中只表达这一动机，显式规划算法尚未接入。

### 图二：现在怎么运行，后续怎么接

前端统一进入 FastAPI，后端分为多轮对话、RAG 知识问答与 Agent 工具分析三条路径。文本模型使用 LangChain 的 ChatDeepSeek 适配。知识库使用递归切分和 InMemoryVectorStore，原文及片段保存到 SQLite；嵌入目前是本地字符哈希基线。

工具分析中，Planner 选择下一步，Executor 校验并执行，实际结果更新状态后再进入下一轮。四个工具负责读取线路表、代码计算负载比值、知识检索与报告生成。负载比值是 abs(active_power_mw) / limit_mw × 100%，超过 100% 仅表示超过给定有功限值，不推断整体电网安全。

后续研究在虚线区域：补充目标判据与动作语义，接入显式规划和验收方法。当前已有工具、执行器、页面与轨迹可复用，但目标描述、动作效果、失效传播和研究验收仍需补充实现。图片理解当前沿用独立模型适配。

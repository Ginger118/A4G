实际调用逻辑

App维护导航、登录和历史选择；ChatWorkspace保存当前会话与消息视图，底部输入发送后立即追加用户和助手位置。readEventStream处理跨字节UTF-8/CRLF、错误与done，不用定时器伪造打字。

普通对话：streaming.build_stream_router -> chat_events -> llm.stream_completion -> ChatDeepSeek.astream。每个增量即时发送；正常完成后保存完整消息，停止或断开会关闭生成器并标记cancelled。部分失败保留任务观察但不作为完整assistant上下文。

资料：upstream_events读取LangGraph updates与custom。compose_response在模型生成时用get_stream_writer转发可见正文；非模型的澄清和固定草案一次发送。最终TaskContract仍按能力、来源和权限校验，不授予执行权。

工具：原任务API/Executor不变，generate_power_report流式写入正文观察，GET events每150ms取新观察后发送；正式报告校验保存，answer_final替换预览。引用失败只返回error，不发布成功done。

消息记录和所有检索/原件继续按用户隔离。对话区可独立滚动；切页面保持挂载，换账号清理选择状态。窄屏用右侧抽屉。此轮未实现网络断线自动续传、任意节点恢复或生产并发保证。
